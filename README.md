# ATLAS 公開資料層

都更／危老法規與建材規格的靜態發布層。
資料由 NocoDB（NAS）定期導出，透過 GitHub Pages CDN 提供。

## 目錄

```
data/laws/index.json     法規清單（輕量，先載這個）
data/laws/{PCODE}.json   各法規全文
law.html                 法規查詢頁
```

## 資料來源與免責

法規原文源自全國法規資料庫。本資料僅供參考，
正式引用請以官方公告版本為準。

## 不包含

本 repo **僅存放公開資料**。以下資料永遠不會發布至此：

- 實務註記與經驗判斷
- 案件成本、實際成交價
- 地主與客戶資料
