金鑰與密碼放哪
Supabase Publishable key → 寫在網頁裡，可公開
Supabase Secret key     → 只在 Mac：~/Downloads/.atlas_env（chmod 600）
                          從不寫進任何 html / py / 對話
登入帳號                → Supabase Auth 唯一使用者；忘記密碼到 Auth → Users 重設
GitHub / Vercel         → 同一個 GitHub 帳號登入
NAS                     → DS920+ 管理員密碼（實體備忘）

    
重灌／換機要做的事
1. 裝 Python 3 + pip3 install requests pillow
2. 從 GitHub atlas-public-data 取回三個 html（不含腳本）
3. 腳本：atlas_law_push_sb_v2.py / atlas_local_laws.py（Downloads）
4. 建 ~/Downloads/.atlas_env 放 Secret key
5. 法規資料：到 law.moj.gov.tw/api/swagger 重抓 ChLaw.json.zip、ChOrder.json.zip
6. Supabase 不用動；若要重建，SQL 依序 01→03→04→05→06→07

    
怎麼更新網頁與程式碼
三個網頁（index.html / law.html / finder.html）都放在 GitHub repo「atlas-public-data」，
Vercel 盯著這個 repo，檔案一變就自動重新部署（約 30–60 秒）。

更新任一網頁
  1. 拿到新檔（Claude 給的，或自己改的）
  2. GitHub → atlas-public-data → Add file → Upload files → 拖進去（同名即覆蓋）→ Commit changes
  3. 等 Vercel 綠燈，瀏覽器 Cmd+Shift+R 強制重新整理
  4. 看分頁標題版本號對不對（例：法規條文庫 v2.2）
  改檔名的情況：本機先改好名字再上傳，不要在 GitHub 網頁改名

新增一個網頁（例：之後的案件清單 cases.html）
  同上上傳；網址就是 https://atlas-public-data.vercel.app/cases.html
  記得在 index.html「三個入口」加卡片，頁面本身加「⌂ 首頁」鈕

腳本（.py）不上 GitHub
  放 Mac ~/Downloads；密鑰讀 ~/Downloads/.atlas_env
  目前三支：atlas_law_push_sb_v2.py（中央法規季更）
           atlas_local_laws.py（地方法規登記＋PDF 上傳）
           atlas_crawler.py（建材爬蟲，重寫中）

資料庫結構（SQL）
  每次改結構都是一支新的 supabase_NN_xxx.sql，在 Supabase SQL Editor 跑一次
  已跑：01 法規條文 · 03 全表 · 04 Storage · 05 law-pdf · 06 法規主檔 · 07 ui_state
  改 SQL 不會動到資料；重建整個專案才需要從 01 依序跑

版本號慣例
  網頁 title 裡：index v6.x / law v2.x / finder v6.x；小修 +0.0.1，加功能 +0.1
  每次上線後把版本寫進「決策紀錄」或時程表的 ✅ 備註
