為什麼不做 RAG 向量化（決策 D8，2026-08-22）
本庫定位為 建經公司／都更推動師／估價師的專業工具， 專業使用者要的是「都市更新條例第 27 條，113年11月13日修正版，原文如下」， 不是「大概跟你講這個議題是怎樣」。
向量檢索最弱的正是精準引用——它找語意相近的片段，可能給相近但不對的條文， 或把兩部法規的條文混在一起。在法規領域，這是專業信譽的風險。
而 API 取得的資料天然就是「一條一筆」，條號本身就是最精準的檢索鍵， 不需要切塊（chunking），也沒有切壞語意的問題。 語意搜尋列為第二階段加值，等資料層穩定後再評估。
自動更新機制（階段 A 待完成）
每季由 Synology 工作排程器執行 atlas_law_sync.py → 比對 LawModifiedDate → 有異動則更新條文並寫入「法規異動紀錄」表 → 儀表板顯示「N 筆待覆核」紅點。
⚠️ 已知限制：法務部伺服器憑證缺 Subject Key Identifier， Python 3.13+ 會拒絕連線，腳本已內建降級重試；排程環境需先驗證。
尚未納入（需另尋來源）
全國法規資料庫不收自治條例與行政規則，以下需以輕量爬蟲取得（階段 D）：
新北市都市更新自治條例 · 新北市都更補助辦法 · 都更事業範圍內國有土地處理原則
新北市法規查詢系統 web.law.ntpc.gov.tw 無 API； 新北開放資料平台有 API 但不含法規。約 20 頁以內， requests + BeautifulSoup 即可，不需 Scrapy。
第二層文件（手冊／問答集，階段 D）
都市更新事業作業手冊（109 版）· 臺北市危老重建問答集 · 都市更新相關法令彙編上下冊

§ 05AI 人設 — 四大板塊展開

🪪 基礎人設（Identity）

  • ◆ 定位：個人作戰參謀，不是對外發言機器人
  • ◆ 語言：繁體中文，穩定、專業、具同理心
  • ◆ 建材專家層：十年經驗是差異化優勢
  • ◆ 對象感知層：自動辨識地主 / 建商 / 政府窗口，切換語氣深度
  • ◆ 都更知識分層：法定流程 vs 商務慣例
  • ◆ 學習成長：主動補充、不假設全知

🔍 檢索邏輯（Retrieval）

  • ◆ 來源優先序：① 親自確認 ② NocoDB ③ 上傳文件 ④ 網路
  • ◆ 建材查詢：「那個白霧面 60 大板」→ 自動比對 NocoDB
  • ◆ 法規查詢：標記「109 版手冊」vs「最新公告」
  • ◆ 跨表關聯：案件 ↔ 推動師 ↔ 建材
  • ◆ 找不到時：明確回應「找不到」，提示下一步

📊 數據處理（Data Handling）

  • ◆ 土開試算：容積率/建蔽率/允建容積/共同負擔自動化
  • ◆ 費用分項：結構評估/補助/信託/拆遷補償
  • ◆ 估算值 vs 實際值 清楚標示
  • ◆ 版本管理：重要試算存 NocoDB，可回溯
  • ◆ 單位一致性：坪/m²/戶數/比例自動換算

🔒 安全紅線（Guardrails）

  • ◆ 地主個資：姓名/地籍/同意書 不對外輸出
  • ◆ 法律邊界：AI 提供參考，最終由推動師確認
  • ◆ 估算免責：加注「以實際簽約為準」
  • ◆ 競爭情報：案件資訊不提供給非授權對象
  • ◆ NocoDB 寫入 / 刪除：必須二次確認

§ 07隱私與安全紅線

🔴 地主個資絕對紅線
  • 姓名、身分證號、地籍謄本資料 → 絕不輸出到任何外部格式
  • 地主同意率（%）→ 僅顯示聚合數字，不顯示個別態度
  • 簽名/印章/同意書掃描 → 禁止分析、複製、傳輸
  • AI 提及特定地主時，一律以「地主 A/B/C」代稱
🔴 法律邊界紅線
  • 法規解釋末尾加注：「以主管機關最新公告為準，建議確認」
  • 估算數字加注：「估算值，以實際簽約/鑑定為準」
  • 不替代律師、地政士、估價師出具正式意見
  • 涉訴訟/調解/強制執行 → 一律建議諮詢專業法律人
🟡 NocoDB 操作安全
  • 刪除操作：必須輸入確認指令 + 顯示受影響筆數
  • 批次更新（>10 筆）：顯示預覽清單再執行
  • 自動爬蟲同步：不覆蓋手動填寫的備註欄
  • 每次重要操作寫入操作日誌（時間/動作/影響範圍）
🟡 案件競爭情報
  • 案件地址、基地面積、同意率 → 不出現在可分享連結
  • AI 對話記憶庫 → 只有本人帳號可存取
  • 輸出報告時敏感欄位自動遮蔽（可手動解鎖）
  • NAS 外網存取 → 走 Tailscale VPN，不開放公網

import os, sys, time, json, argparse
from urllib.parse import urljoin
import requests
from bs4 import BeautifulSoup
from dotenv import load_dotenv
from tqdm import tqdm
from atlas_nocodb import upsert_product, download_image

load_dotenv()

# ═══ 改這區塊就能爬新廠牌 ═══
BRAND_NAME    = "白馬"          # 改這
FACTORY_NAME  = "白馬陶瓷"       # 改這
BASE_URL      = "https://whitehorse.com.tw"
LIST_URL      = f"{BASE_URL}/overview/tw"   # 改這:產品列表頁
LIBRARY_DIR   = f"/volume1/atlas-library/磁磚/{BRAND_NAME}"

# CSS selector(從 F12 Elements 複製)
SEL_PRODUCT_CARD = "div.product-item"       # 改這
SEL_PRODUCT_NAME = "h3.product-title"        # 改這
SEL_PRODUCT_IMG  = "img.product-img"          # 改這
SEL_PRODUCT_LINK = "a.product-link"          # 改這

HEADERS = {
    "User-Agent": "Mozilla/5.0 (Macintosh; ATLAS-Crawler)",
    "Accept-Language": "zh-TW,zh;q=0.9",
}

def fetch(url):
    """包裝 requests，加入 timeout、retry、rate limit"""
    for attempt in range(3):
        try:
            r = requests.get(url, headers=HEADERS, timeout=15)
            r.raise_for_status()
            time.sleep(0.5)  # 禮貌性暫停，別太快
            return r.text
        except Exception as e:
            print(f"⚠ 第 {attempt+1} 次失敗: {e}")
            time.sleep(2 ** attempt)
    return None

def parse_product_detail(url):
    """進入單一產品頁，抽取完整欄位"""
    html = fetch(url)
    if not html: return None
    soup = BeautifulSoup(html, "lxml")

    # TODO: 根據網站實際 DOM 結構填入
    return {
        "工廠": FACTORY_NAME,
        "品牌": BRAND_NAME,
        "代理": "",
        "型號": soup.select_one(".model").text.strip(),
        "產品名稱": soup.select_one(".title").text.strip(),
        "尺寸": soup.select_one(".size").text.strip(),
        "主系列": soup.select_one(".series").text.strip(),
        "面感": soup.select_one(".surface").text.strip(),
        "產地": soup.select_one(".origin").text.strip(),
        "來源網址": url,
        # ... 其他欄位
    }

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--limit", type=int, default=None, help="測試用")
    ap.add_argument("--images", action="store_true")
    ap.add_argument("--colors", action="store_true")
    args = ap.parse_args()

    os.makedirs(LIBRARY_DIR, exist_ok=True)
    print(f"🏭 開始爬 {BRAND_NAME} · {LIST_URL}")

    # 1. 抓列表頁
    html = fetch(LIST_URL)
    soup = BeautifulSoup(html, "lxml")
    cards = soup.select(SEL_PRODUCT_CARD)
    if args.limit:
        cards = cards[:args.limit]
    print(f"   找到 {len(cards)} 件產品")

    # 2. 逐件爬詳情 + 圖片 + 寫入 NocoDB
    for card in tqdm(cards, desc="爬取中"):
        link_el = card.select_one(SEL_PRODUCT_LINK)
        detail_url = urljoin(BASE_URL, link_el["href"])

        product = parse_product_detail(detail_url)
        if not product: continue

        if args.images:
            img_el = card.select_one(SEL_PRODUCT_IMG)
            if img_el:
                img_url = urljoin(BASE_URL, img_el.get("src", ""))
                img_path = download_image(img_url, LIBRARY_DIR, product["型號"])
                product["圖檔"] = img_path

        if args.colors and product.get("圖檔"):
            from colorthief import ColorThief
            ct = ColorThief(product["圖檔"])
            palette = ct.get_palette(color_count=6)
            product["色盤"] = json.dumps([f"#{r:02x}{g:02x}{b:02x}" for r,g,b in palette])

        upsert_product(product)

    print("✅ 完成")

if __name__ == "__main__":
    main()

from playwright.sync_api import sync_playwright

# ═══ 改這區塊就能爬新廠牌 ═══
BRAND_NAME   = "瑪摩"
FACTORY_NAME = "台灣瑪摩"
BASE_URL     = "https://marmotaiwan.com"
LIST_URL     = f"{BASE_URL}/product-search"
LIBRARY_DIR  = f"/volume1/atlas-library/磁磚/{BRAND_NAME}"

SEL_PRODUCT_CARD = "div.product-card"
SEL_NEXT_PAGE    = "a.next-page"

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--limit", type=int, default=None)
    ap.add_argument("--images", action="store_true")
    ap.add_argument("--colors", action="store_true")
    ap.add_argument("--headless", action="store_true", default=True)
    args = ap.parse_args()

    os.makedirs(LIBRARY_DIR, exist_ok=True)

    with sync_playwright() as p:
        browser = p.chromium.launch(headless=args.headless)
        context = browser.new_context(
            user_agent="Mozilla/5.0 ATLAS-Crawler",
            locale="zh-TW",
        )
        page = context.new_page()
        page.goto(LIST_URL, wait_until="networkidle")

        # 1. 自動翻頁收集所有產品連結
        all_links = []
        while True:
            page.wait_for_selector(SEL_PRODUCT_CARD, timeout=10000)
            cards = page.query_selector_all(SEL_PRODUCT_CARD)
            for c in cards:
                link = c.query_selector("a")
                if link:
                    all_links.append(link.get_attribute("href"))

            next_btn = page.query_selector(SEL_NEXT_PAGE)
            if not next_btn or not next_btn.is_enabled():
                break
            next_btn.click()
            page.wait_for_load_state("networkidle")

        if args.limit:
            all_links = all_links[:args.limit]

        # 2. 逐件爬詳情
        for url in tqdm(all_links, desc="爬取中"):
            page.goto(url, wait_until="networkidle")
            product = {
                "工廠": FACTORY_NAME,
                "品牌": BRAND_NAME,
                "型號": page.text_content(".model"),
                # ... 其他欄位用 page.text_content(selector) 抽
                "來源網址": url,
            }

            if args.images:
                img_url = page.get_attribute(".main-image img", "src")
                if img_url:
                    product["圖檔"] = download_image(img_url, LIBRARY_DIR, product["型號"])

            upsert_product(product)

        browser.close()
    print("✅ 完成")

if __name__ == "__main__":
    main()

# atlas_nocodb.py · 共用模組
# 所有爬蟲 import 這個檔案，集中管理 NocoDB 寫入邏輯

import os, requests, hashlib
from urllib.parse import urlparse
from dotenv import load_dotenv

load_dotenv()

NOCODB_URL   = os.getenv("NOCODB_URL")
NOCODB_TOKEN = os.getenv("NOCODB_TOKEN")
TABLE_ID     = os.getenv("TABLE_ID")  # 表五 · 產品與廠牌總庫

HEADERS = {
    "xc-token": NOCODB_TOKEN,
    "Content-Type": "application/json",
}

def find_by_model(model):
    """根據型號查詢是否已存在"""
    url = f"{NOCODB_URL}/api/v2/tables/{TABLE_ID}/records"
    r = requests.get(url, headers=HEADERS, params={
        "where": f"(型號,eq,{model})",
        "limit": 1,
    })
    records = r.json().get("list", [])
    return records[0] if records else None

def upsert_product(product):
    """有就更新、沒有就新增。保留手動備註欄位不覆蓋"""
    existing = find_by_model(product["型號"])

    if existing:
        # 更新，但保留「備註」欄位
        record_id = existing["Id"]
        product.pop("備註", None)  # 移除備註不覆蓋
        url = f"{NOCODB_URL}/api/v2/tables/{TABLE_ID}/records"
        r = requests.patch(url, headers=HEADERS, json={**product, "Id": record_id})
        return "updated"
    else:
        # 新增
        url = f"{NOCODB_URL}/api/v2/tables/{TABLE_ID}/records"
        r = requests.post(url, headers=HEADERS, json=product)
        return "created"

def download_image(img_url, folder, filename):
    """下載圖片到 NAS，重複不重下"""
    if not img_url.startswith("http"):
        return None
    ext = os.path.splitext(urlparse(img_url).path)[1] or ".jpg"
    safe_name = "".join(c for c in filename if c.isalnum() or c in "-_")
    filepath = os.path.join(folder, f"{safe_name}{ext}")

    if os.path.exists(filepath):
        return filepath

    r = requests.get(img_url, timeout=30, stream=True)
    if r.status_code == 200:
        with open(filepath, "wb") as f:
            for chunk in r.iter_content(8192):
                f.write(chunk)
        return filepath
    return None

📋 PHASE 12 · 交接文件 SOP

操作教學▾

交接文件不是給「別人」看的，主要是給 三個月後的你自己 看的。 當系統越複雜，你就越記不住所有細節。每次規模變更都要產出新版本。

什麼時候該更新交接文件？

🔴 必須更新（Major）

  • ◆ 換 NAS 硬體或升級 DSM 大版本
  • ◆ 新增 Docker container（如 Qdrant、AI 服務）
  • ◆ 資料庫架構變更（新增表、欄位大改）
  • ◆ 改了反向代理或網路架構
  • ◆ 更換雲端備份服務商
  • ◆ API Token 或密碼重設
  • ◆ Phase 完成（例如 Phase 2 → 升到 v4.2）

🟡 建議更新（Minor）

  • ◆ 新增 NocoDB 表或大量欄位
  • ◆ 新增爬蟲目標廠牌
  • ◆ 排程器新增或調整任務
  • ◆ 帷幄 / 選色表 UI 大改
  • ◆ 發現新的 bug 或 workaround
  • ◆ 每 2 個月 沒更新 → 也該更新一次做健檢
